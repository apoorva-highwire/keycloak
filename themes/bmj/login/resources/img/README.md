# publisher-example images

Drop this publisher's real logo here as `logo.svg` (or `.png`) — it's already
referenced by `--hw-logo-url` in `../css/publisher-overrides.css`. Rename the
file or update that variable if using a different filename/format.

When copying this folder to create a real publisher theme (see
`../../../README.md`), this is the one asset every publisher theme needs.
